# TechGURU

Веб-приложение сервисного центра по ремонту электроники и бытовой техники. Курсовой проект: публичный сайт, личные кабинеты клиента, мастера и администратора, серверное API и облачная база данных.

**[Открыть работающий сайт](https://techguru.techguru-w.workers.dev/)** · **[Инструкция развёртывания](docs/deployment.md)**

Исходный код доступен публично. Опубликованный сайт работает на Cloudflare независимо от локального компьютера разработчика.

## Технологии

| Часть системы | Технологии |
|---|---|
| Интерфейс | Vue 3, Vue Router, Vite, Tailwind CSS |
| Сервер | TypeScript, Cloudflare Workers |
| База данных | Cloudflare D1 / SQLite |
| Проверка данных | Zod, общие контракты клиента и сервера |
| Карта и адреса | Яндекс Карты и Геокодер |
| Вход и почта | Google OAuth, отправка кодов через Gmail SMTP |

## Возможности

| Роль | Основные действия |
|---|---|
| Гость | Просмотр услуг, цен и точек приёма; регистрация и вход |
| Клиент | Создание заявки с фотографиями, выбор времени и формата обслуживания, просмотр ремонта и сметы, согласование изменения стоимости, отмена доступной заявки, отзыв и уведомления |
| Мастер | Работа с назначенными заявками, расписанием и навыками; запрос и учёт деталей, завершение ремонта, обращения администратору и просмотр отзывов |
| Администратор | Управление заявками, мастерами, пользователями и справочниками; ручное назначение, склад и закупки, статистика, аудит и экспорт CSV |

- Подтверждение почты одноразовым кодом и автоматический вход после подтверждения.
- Вход по паролю или через Google, восстановление пароля через подтверждённую почту.
- Проверка прав роли и владельца заявки, защищённые сессии, хеширование паролей, CSRF и ограничение попыток входа.
- Автоназначение мастера с учётом навыков, доступности, расписания и дневного лимита.
- Согласование новой сметы клиентом перед дополнительными работами.
- Резервирование, выдача, расход и возврат деталей; заказы поставщикам и приёмка поставок.
- Поиск, фильтры, уведомления, расчёты и отчёты.
- Адаптивный интерфейс для компьютера и телефона, светлая и тёмная темы.

Выезд мастера доступен только по Москве. Также можно выбрать приём устройства в сервисном центре. Телефон используется как контактный и проверяется по формату; SMS-подтверждение не подключено. Онлайн-оплата не реализована.

## Запуск на своём компьютере

Требуются **Node.js 24+** и **npm**. Для локальной демо-базы аккаунт Cloudflare не нужен.

```sh
git clone https://github.com/guru-okak/TechGURU.git
cd TechGURU
npm ci
npm run db:setup
```

Скопируйте `.env.example` в `.env`. Ключ `VITE_YANDEX_MAPS_API_KEY` нужен для карты, `YANDEX_GEOCODER_API_KEY` — для проверки адресов. Без собственных настроек внешних сервисов карта, подтверждение почты и Google OAuth не будут работать как на опубликованном сайте. Для проверки локального входа используйте демо-аккаунты ниже.

Запустите API и интерфейс в двух терминалах:

```sh
# Терминал 1 — сервер и локальная БД
npm run dev:api
```

```sh
# Терминал 2 — интерфейс
npm run dev
```

Откройте [http://127.0.0.1:5173](http://127.0.0.1:5173). Проверка API: [http://127.0.0.1:8787/api/health](http://127.0.0.1:8787/api/health). Используйте один и тот же адрес сайта во время проверки. После изменения серверного кода перезапускайте API.

## База данных и проверки

Девять миграций в `db/migrations` создают 23 таблицы, включая одноразовые коды подтверждения и восстановления доступа. Демо-данные формируются из `db/seeds/demo.mjs`. Локальная база хранится в `.local/d1` и сохраняется после перезапуска API. Облачная D1 — отдельная база.

```sh
npm run db:check          # Проверка структуры локальной БД
npm run typecheck:server  # Типизация сервера
npm run test:server       # Серверные тесты
npm run test:d1           # Проверка сценариев D1 и сохранности данных
npm run build            # Сборка интерфейса
npm run check            # Типизация, интеграционные тесты и сборка
```

Интеграционные проверки используют временные базы. Большие наборы на части экранов загружаются целиком; серверная пагинация всех списков пока не реализована.

## Публикация и секреты

Сайт, API и облачная БД размещены на Cloudflare Workers / D1. Конфигурация облака — `wrangler.production.jsonc`, локальная — `wrangler.jsonc`. Для собственного развёртывания нужны свои ресурсы и секреты: см. [инструкцию](docs/deployment.md).

В репозиторий не входят рабочая БД, `.env`, `.dev.vars`, `.local`, SMTP-пароль, OAuth-секреты, ключ подписи сессий и пароли облачных пользователей. Идентификаторы ресурсов Cloudflare в конфигурации сами по себе не предоставляют доступ к ним.

GitHub хранит исходники. GitHub Pages не используется: серверное API и D1 обслуживаются Cloudflare.

## Структура проекта

```text
src/       — страницы, компоненты и стили интерфейса
server/    — API, авторизация, репозитории и серверные сервисы
shared/    — общие контракты и правила
db/       — миграции и демо-наполнение
tests/    — автоматические проверки
scripts/  — локальный запуск, сборка и обслуживание
docs/     — технические материалы и инструкция развёртывания
```

Материалы в `docs` включают исторические отчёты разработки; актуальные инструкции запуска находятся в этом README и `docs/deployment.md`.
