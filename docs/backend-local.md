# Локальная серверная часть

Актуальная инструкция запуска находится в [README](../README.md). Интерфейс подключён к API, авторизация и регистрация используют D1. Все восемь миграций создают 22 предметные таблицы.

Команды первого запуска: `npm ci`, `npm run db:setup`. Затем в отдельных терминалах `npm run dev:api` и `npm run dev`. Данные сохраняются в `.local/d1`, этот каталог исключён из Git. JWT-секрет локальной среды создаётся автоматически и также не публикуется.

`npm run check` проверяет типизацию, интеграционные сценарии и сборку. `npm run test:d1` использует изолированную БД и проверяет сохранение после перезапуска. Рабочую БД заменять тестовыми файлами не следует.

wrangler.jsonc настроен локально: ID D1 — заполнитель, production-развёртывание требует отдельной конфигурации. API-ключи Яндекса задаются через .env по .env.example. Внешняя отправка email/SMS и оплата не подключены.
