# Анимации и изображения — 01.11.2026

Ориентиры: https://www.ismash.com/ и https://www.samsung.com/us/support/service/. Просмотрены доступные страницы и стили элементов. У iSmash обнаружены короткие переходы элементов управления (в том числе 0,2 с), в меню Samsung — opacity 0,5 с. Это ориентиры характера движения, а не замер всей анимации сайтов; часть внешнего медиа не воспроизводилась, uBreakiFix вернул 403.

В TechGURU собственная общая система: отклик 160–220 мс, появление 360–420 мс, небольшие перемещения 6–12 px; карточки поднимаются на 3 px при наведении мышью, фон карточки точки увеличивается до 1,025. Блоки появляются один раз при входе в область просмотра. Вложенные блоки не анимируются повторно одновременно с родителем; формы и таблицы не получают отдельного последовательного появления строк. Для FAQ добавлено появление ответа. Задержка каскада ограничена, на мобильном нет эффектов наведения. Бесконечных декоративных анимаций не добавлено.

prefers-reduced-motion отключает новые появления и движения; смена настройки отменяет текущие эффекты. Контент не скрыт в CSS до загрузки JavaScript. Без IntersectionObserver страница остаётся доступна. Тест в Node с имитацией браузерных API проверил обычное появление, отмену, reduced-motion, освобождение наблюдателей и отсутствие IntersectionObserver. Это проверка логики, не замена ручного испытания системной настройки браузера.

Новый отдельный баннер suppliers.webp создан для поставщиков, audit.webp — для аудита. Точкам приёма выделено ранее не используемое reception-detail.webp. Заказы сохраняют orders.webp; совпадение баннеров этих административных разделов устранено. Изображения сохранены локально в проекте, оптимизированы в WebP.

Production-сборка проходит. В браузере проверены загрузка нового изображения поставщиков и CSS-переменных, отсутствие горизонтального переполнения. Серверный функционал и БД не изменялись. Резервная копия предыдущих файлов — в папке «Резервные копии/Анимации_20261101_230724».
