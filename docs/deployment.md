# Развёртывание TechGURU

Работающий сайт: https://techguru.techguru-w.workers.dev/ . Интерфейс и API `/api/*` обслуживаются одним Cloudflare Worker по HTTPS, данные хранятся в облачной D1. Локальный компьютер для работы опубликованного сайта не нужен.

## Настройки

Облачная конфигурация — `wrangler.production.jsonc`, локальная — `wrangler.jsonc`. Для собственного развёртывания замените `account_id`, `database_id`, имя Worker и имя D1 своими значениями. Идентификаторы ресурсов не дают доступа к ним; для публикации нужна авторизация Cloudflare.

Примените все девять миграций из `db/migrations` к своей D1. Настройте серверные секреты через Wrangler, не добавляя их в Git:

- `JWT_SECRET` — случайный ключ подписи сессий.
- `YANDEX_GEOCODER_API_KEY` — серверная проверка адресов.
- `SMTP_USER`, `SMTP_PASSWORD` — адрес отправителя Gmail и пароль приложения для писем с кодами.
- `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET` — клиент Google OAuth для входа.

Ключ карты `VITE_YANDEX_MAPS_API_KEY` задаётся при сборке интерфейса. Для ключей Яндекса настройте ограничения по доменам или IP согласно используемому API. В Google OAuth добавьте адрес перенаправления `https://ваш-домен/api/auth/google/callback`.

## Сборка и публикация

```sh
npm ci
npm run typecheck:server
npm run build
npx wrangler deploy --config wrangler.production.jsonc
```

`APP_ENV=production` и `ENABLE_LOCAL_CHECKS=false` отключают локальные диагностические маршруты. Перед первым запуском собственного экземпляра примените миграции и подготовьте пользователей. Скрипт `scripts/prepare-production.mjs` создаёт приватные файлы с уникальными паролями и SQL в `.local`; не публикуйте эти файлы и не запускайте наполнение поверх рабочей базы без проверки.

## Что не входит в репозиторий

`.env`, `.dev.vars`, `.local`, файлы БД, рабочие сессии, пароли облачных аккаунтов, SMTP и OAuth-секреты исключены из Git. Аккаунты и пароли из README предназначены только для отдельной локальной демо-базы и не являются данными доступа к опубликованному сайту.

GitHub Pages не используется: это статический хостинг, который сам по себе не запускает Cloudflare Worker и D1. Текущий сайт размещён целиком на Cloudflare.
