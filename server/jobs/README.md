# Регламентные задачи

run.ts вызывается scheduled handler в server/index.ts. Часовая задача выполняет эскалации, напоминания, автозакрытие, обеспечение заявок и проверку закупок; ежедневная сохраняет SQL в binding BACKUPS при облачном подключении R2.

Локальный scripts/dev.mjs запускает часовые проверки и ежедневные проверенные SQL/SQLite-копии. Подробности: ../../docs/Подключение_сайта_к_API_2026-11-02.md.
